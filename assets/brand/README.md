# Silkwood brand assets

- `logo-on-light.*`: copper-and-ochre signature for light backgrounds.
- `logo-on-dark.*`: cream-and-ochre signature for dark copper backgrounds.
- `logo-mark.*`: transparent SW monogram.
- `logo-mark-on-copper.*`: cream SW monogram for copper backgrounds.
- `favicon.ico` and the PNG favicon files: application/browser icons.
- `colors.json`, `colors.css`, and `color-palette.png`: palette tokens and swatches.

PNG versions retain transparency where appropriate. JPEGs are supplied with the intended brand background.
